## データ型

| 型 | 書き方 | 例 |
|---|---|---|
| 文字列 | `"展開"` / `'そのまま'` | `"Hello $name"` |
| 整数 | `[int]` | `$x = 42` |
| 配列 | `@()` | `$a = @(1,2,3)` |
| ハッシュテーブル | `@{}` | `$h = @{Key="Val"}` |
| 順序付きHT | `[ordered]@{}` | キー順序を保持 |

## 比較演算子

| 演算子 | 意味 | 演算子 | 意味 |
|---|---|---|---|
| `-eq` | 等しい | `-ne` | 等しくない |
| `-gt` | より大きい | `-lt` | より小さい |
| `-like` | ワイルドカード | `-match` | 正規表現 |
| `-contains` | 配列に含む | `-in` | ～の中にある |
| `-and` | 論理AND | `-or` | 論理OR |
| `-replace` | 正規表現置換 | `-split` | 分割 |

## 配列操作

```powershell
$a = @(1,2,3)
$a += 4        # 追加
$a[0]          # 最初
$a[-1]         # 最後
$a[1..2]       # スライス
$a.Count       # 要素数
```
